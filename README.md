# Portfólio Pessoal

## 📌 Sobre o projeto
Portfólio pessoal desenvolvido para apresentar meus conhecimentos, habilidades e projetos na área de desenvolvimento web.

O projeto também tem como objetivo acompanhar minha evolução prática durante os estudos de programação.

## 🛠️ Tecnologias utilizadas
- HTML5: estruturação das páginas.
- CSS3: estilização e organização visual.

## 🎯 Objetivos
- Aplicar conhecimentos de desenvolvimento web.
- Apresentar projetos e habilidades técnicas.
- Aprimorar minhas habilidades em programação.
- Expandir o portfólio com novas tecnologias.

## 🚀 Status do projeto
**Em desenvolvimento.**

Novas funcionalidades e melhorias serão implementadas conforme meu aprendizado, incluindo a utilização de JavaScript.
